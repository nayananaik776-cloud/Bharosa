# Bharosa Fraud Guardian

Bharosa is a proactive payment-safety system designed especially for digitally vulnerable users such as rural users, first-time digital-payment users, elderly users, and users with limited digital/financial literacy.

## Architecture
- **backend/**: FastAPI backend, risk orchestration, and API.
- **android/**: Android application acting as the guardian.
- **frontend/**: Simulated payment UI and demo.
- **ml/**: ML and NLP models for signal extraction and intelligence.
